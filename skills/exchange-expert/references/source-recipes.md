# Источники и рецепты доступа

Читать перед поиском первоисточника. Раздел «Доступность из среды» отражает проверку 07.10.2026 на главных страницах, не на конкретных документах. Перепроверяй: прокси и сайты меняются.

## Иерархия источников для вопроса по российскому рынку

1. **Закон:** `publication.pravo.gov.ru`. Рецепт получения текста (eoNumber, http вместо https, экранирование в заголовках) лежит в `skills/legal-re-reserch/references/ru-primary-sources.md`; не изобретай его заново.
2. **Акты Банка России:** `cbr.ru`; рецепт поиска по номеру там же.
3. **Правила и решения биржи:** сайт Московской биржи, раздел листинга ([требования для акций](https://www.moex.com/a2584)) и пресс-центр (новости об изменениях правил). Сообщение биржи о собственном решении это первоисточник по факту решения; сам текст правил открывай отдельно.
4. **Параметры контрактов и бумаг:** ISS API Мосбиржи, см. ниже.
5. **Вторичные источники** (новости, обзоры юрфирм, выдача поиска): годятся, чтобы найти акт или правило, но помечаются `[вторичный]`.

Чего не делать: опираться на пересказ в прессе как на текст нормы; брать номер статьи из памяти; переносить вывод по американскому или европейскому режиму на Россию по аналогии.

## ISS API Мосбиржи (проверено 07.10.2026)

Открывается без авторизации. Ответ в JSON, параметр `iss.meta=off` убирает метаданные, `iss.only=securities` оставляет нужный блок, `securities.columns=` задаёт поля.

Фьючерсы:

```
https://iss.moex.com/iss/engines/futures/markets/forts/securities.json?iss.meta=off&iss.only=securities&securities.columns=SECID,SHORTNAME,LASTTRADEDATE,ASSETCODE,SECTYPE,LATNAME,MINSTEP,STEPPRICE,LOTVOLUME,INITIALMARGIN
```

Опционы:

```
https://iss.moex.com/iss/engines/futures/markets/options/securities.json?iss.meta=off&iss.only=securities&securities.columns=SECID,SHORTNAME,LASTTRADEDATE,ASSETCODE,SECTYPE,STRIKE,OPTIONTYPE
```

Что подтвердилось: фьючерсы возвращают базовый актив, последний торговый день, шаг цены, стоимость шага, размер лота, начальную маржу. Опционы возвращают страйк и тип; вокруг 40 тысяч строк, фильтруй по `ASSETCODE`. Запрос `SETTLEPRICE` в списке колонок фьючерсов был отклонён молча: колонка не вошла в ответ. Не обещай расчётную цену из этого запроса, ищи её в другом блоке API после проверки.

Оформление: любое число из API идёт с датой запроса и пометкой «данные биржи на дату». Тяни скриптом с `python3 -I`, ответ сохраняй в рабочую папку сессии.

## Доступность из среды (07.10.2026)

| Ресурс | Результат | Что делать |
|---|---|---|
| moex.com, iss.moex.com, cbr.ru | открываются | основной контур |
| publication.pravo.gov.ru | по `http` открывается, по `https` обрыв соединения | использовать `http` и ordinary User-Agent |
| esma.europa.eu, nyse.com, nasdaq.com, eurex.com, lseg.com, fca.org.uk | открываются | сравнительная база |
| spbexchange.ru, fs.moex.com | ошибка сертификата на прокси | TLS не отключать; искать через другой путь или просить пользователя приложить документ; тезис помечать `[вторичный]` или `[не проверено]` |
| sec.gov, cmegroup.com | 403 при обычном User-Agent | то же; не подставлять почту пользователя в User-Agent |
| nsd.ru | отвечает, но обрывается по таймауту | повторить; при неудаче тот же порядок |

Если ресурс недоступен, это не повод молчать: ответ даётся с меткой статуса, а в конце названо, какой документ закрыл бы вопрос.
