# Daily Break Read

## Purpose

One article, once a day, so the user can step away from client work for a
few minutes without stepping away from something interesting.

## Who this is for

A lawyer in legal consulting, working mostly in capital markets, financial
and banking law. That context should flavor the *pick*, not gate it — the
whole point of this read is that it is not more legal-work content.

## Picking the article

- Search live (WebSearch/WebFetch). Never answer from memory and never
  invent a link — an unopened link is a made-up link, same rule as the rest
  of this repository.
- Real, dated, and ideally published in roughly the last two weeks. An
  older evergreen piece is fine only if it is genuinely excellent and you
  say how old it is.
- Bias most days toward real science/tech/curiosity stories that have
  nothing to do with law or finance — space, biology, physics, AI research,
  archaeology, medicine, engineering. That is what makes it a break.
- Occasionally, not every day, a finance- or markets-adjacent story earns a
  place as a treat precisely because it's a step removed from casework:
  economic history, a landmark case retrospective, the story behind a
  market event, a fintech curiosity. Never pick routine legal/regulatory
  news the user would already see at work — that defeats the purpose, and
  the `legal-digest-alert` skill in this repository covers that ground
  already.
- Favor outlets with real editorial standards over aggregators or SEO
  content: Nature, Science, Quanta Magazine, MIT Technology Review,
  Scientific American, Ars Technica, The Economist, and — for the
  occasional finance-flavored pick — Reuters, Bloomberg, FT. A precise,
  well-chosen niche source beats a generic listicle every time.
- Skip anything that turns out to be an ad, a listicle, or content-farm
  filler once you actually look at it.

## Delivering it

- Reply directly in chat. This is a quick read, not a document deliverable
  — no docx, no firm template, no citation apparatus.
- Write the reply in Russian, per this repository's language default, even
  when the source is in English: translate and adapt the summary rather
  than pasting the original text.
- Shape: one short line on why this particular piece (tuned to this
  reader), then a compact summary long enough to actually satisfy
  curiosity — a few short paragraphs, not a teaser — then the source name,
  publication date, and a link to the original at the end.
- Keep the tone casual and human. This is leisure reading.
- If nothing decent turns up, say so plainly instead of stretching a
  mediocre find into "interesting."

## Cadence

Normally triggered by a daily Routine at 15:00 Moscow time, which opens a
fresh session with the instruction to run this skill. Also fine to run on
an ad-hoc request at any other time.
